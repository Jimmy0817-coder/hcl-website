# HCL 網站更新設計規格

## 參考基準

本網站以用戶提供的既有 HCL 網站及 `https://www.hcl.hk/website/new-web-mobile/index.htm` 為**唯一視覺與資訊架構基準**。更新工作須延續既有專業培訓、工程及認證服務的品牌語氣，而非重新發明品牌；新增的 ISO 客戶名單與專業學會標誌必須成為清晰、可信、易於瀏覽的內容模組。

## 已選方向：專業認證檔案館

### Design Movement

以「Institutional Editorial」企業編輯風格為核心：穩健、可驗證、資訊層次清晰，並以香港專業工程服務的成熟形象為主導。

### Core Principles

1. 讓專業資格、ISO 認證及合作學會以清晰資料層級呈現，避免過度裝飾。
2. 以留白、細緻分隔線和模組化內容帶出企業可信度。
3. 以中英文並列的資訊節奏支援香港本地及國際訪客。
4. 所有標誌均以受尊重、等比例、具足夠呼吸空間的方式展示。

### Color Philosophy

以深海藍建立可靠與工程專業感，以暖白作為閱讀底色，以細小金色重點提示認證及成果。整體不使用炫目的漸變，讓官方標誌與資訊成為視覺主角。

### Layout Paradigm

採用「內容帶」式結構：大型品牌主視覺引導訪客，再以橫向資訊帶交錯展示服務、ISO 客戶名單及學會網絡。學會標誌以非均勻的檔案館式排列展示，避免通用的整齊圖示牆。

### Signature Elements

1. 深藍色垂直索引線，串連認證及會員網絡內容。
2. 帶有細金色標記的章節標題與編號。
3. 以「認證檔案卡」呈現 ISO 客戶名單，每張卡保留充足留白。

### Interaction Philosophy

互動以閱讀導向為先。導覽採用流暢捲動；卡片及標誌在懸停時僅有細微抬升與描邊變化，讓使用者感到內容可探索而不分散注意力。

### Animation

頁面內容以短促、由下而上的淡入方式分段出現，時間維持在 180–260ms；標誌在進入視窗時以低調透明度變化顯示。所有動畫均尊重減少動態效果設定。

### Typography System

中文採用 Noto Sans TC，英文標題採用 Manrope，內文以 Noto Sans TC 為主。英文大標題使用較緊字距及粗體；中文標題維持清晰的字重與較舒展行距；資料名單採用中等字重以利掃讀。

### Brand Essence

**HCL 將可驗證的專業認證、實務培訓與國際專業網絡，帶給香港工程及建築從業者。**

品牌個性：**嚴謹、可靠、具國際視野**。

### Brand Voice

標題與按鈕語氣務實、明確、有證據感，避免空泛承諾。

範例：

> 「以國際標準，建立可持續的專業實力。」

> 「查看 ISO 服務客戶名單」

### Wordmark & Logo

沿用既有 HCL 品牌識別；新增的專業學會標誌只作為合作／認可網絡的視覺證明，絕不改造、拉伸或與 HCL 商標混用。

### Signature Brand Color

**HCL 深海藍 `#103B5C`**：用於主導覽、章節索引與認證資訊焦點。

## Style Decisions

1. 所有 ISO、客戶紀錄及學會網絡章節均設置深海藍索引線與細金色證據標記，讓閱讀節奏如同瀏覽一份專業認證檔案。
2. ISO 客戶與學會標誌均以獨立的檔案項目呈現，保留原始比例及呼吸空間，並以不均勻但有秩序的排列取代一般合作夥伴標誌牆。
3. Noto Serif TC 正式定義為 HCL 的**編輯式中文標題字體**；Noto Sans TC 則用於所有內文、列表與資料內容，平衡溫度、清晰度與工程專業感。

## 2026 品牌真實感重塑

本輪改版將首頁由概念性的「認證檔案館」調整為更接近真實企業使用的 **HCL Brand Reference Site**。主視覺只使用現有 HCL 網站提供的公司標誌與業務影像，不使用自訂圖示、合成顧問肖像、標誌灰階濾鏡或過度擬態的檔案標籤。網站以大型 HCL 標誌、留白、深藍導覽、真實案例標誌及穩定的資料卡結構建立信任；專業學會標誌維持彩色原貌，並設於乾淨白底卡片中。

這個新版以 HCL 的可驗證資料作為主軸：**2001 年開始的顧問服務、3 個區域辦公室、ISO 服務範圍、舊版客戶紀錄及 2007 年開始的考牌指導計劃**。深海藍垂直索引線只作為低調的內容導覽節奏，不作模擬檔案標籤；客戶與學會標誌配以白底資料卡、章節說明及彩色原貌，形成專業而非模板化的實證展示。

## Style Decisions — Members News 更新

1. 首屏以較大型 HCL 正式標誌及 2001 年起的實證資料為主，所有編輯式裝飾均退居次要。
2. 中文服務名稱及日期、ISO、資格等事實資料擁有較高可讀性；英文大寫微標籤只作輔助 metadata。
3. `#103B5C` 是唯一主導品牌色；綠色只用於次級網絡及資格重點，金色只標示日期、認證與成果。
4. ISO、客戶、學會、Members News、歷史與聯絡卡均沿用同一套實證標籤、日期與細分隔線語法。
